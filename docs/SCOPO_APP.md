# Scopo dell'app

Questa app ha lo scopo di offrire un IDE nativo per macOS, in stile Cursor, con un assistente AI integrato chiamato **Coder**.

L'obiettivo principale è permettere a sviluppatori e team di:
- scrivere, modificare e comprendere codice in un ambiente locale SwiftUI;
- interagire in chat con un assistente AI direttamente dentro l'editor;
- scegliere tra più provider LLM (OpenAI API, Codex CLI, Claude Code CLI);
- lavorare su cartelle/progetti locali inviando contesto file all'assistente;
- mantenere cronologia persistente delle conversazioni;
- estendere integrazioni tramite MCP (Model Context Protocol).

In sintesi, l'app unisce editor, contesto del workspace e AI in un unico flusso di lavoro nativo macOS per aumentare velocità e qualità nello sviluppo software.
