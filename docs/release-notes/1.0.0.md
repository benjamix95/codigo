# Codigo 1.0.0

Release notes tecniche (prima release)

## Novità principali

- App macOS nativa in SwiftUI con:
  - Chat AI unificata per provider (OpenAI, Codex CLI, Claude CLI, Gemini CLI).
  - Contesto workspace con apertura progetti e gestione file.
  - Routing provider con salvataggio impostazioni (`Settings`) e supporto MCP.
- Strutture di traccia attività, TODO/plan e activity board integrate nel flusso chat.
- Integrazione tool/terminal migliorata per operazioni operative.

## Sicurezza & stabilità

- Uso di `AppStorage` per configurazioni persistenti in modo prevedibile tra sessioni.
- Controllo accessi TCC conservato (`NSMicrophoneUsageDescription`, `NSSpeechRecognitionUsageDescription`).
- Primo supporto a gestione aggiornamenti applicativi remoti basata su manifest.

## Nota tecnica di rilascio

- Versione app impostata via Info.plist:
  - `CFBundleShortVersionString = 1.0.0`
  - `CFBundleVersion = 1`
  - `LSMinimumSystemVersion = 14.0`
- Aggiornamenti:
  - Manifest pubblico: `docs/update/manifest.json`
  - Flag locali in App Storage:
    - `app_update_check_enabled`
    - `app_update_manifest_url`
  - Stato check aggiornamenti implementato in `App/SoloCodeApp/Sources/AppUpdateCenter.swift`
  - UI impostazioni nella sezione Behavior e banner automatico in app launch.
