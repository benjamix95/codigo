# Scopo dell'app

`Codigo` (CoderIDE) è un IDE nativo per macOS, sviluppato in Swift, pensato per integrare in un unico ambiente:

- editing del codice e gestione del workspace;
- assistenza AI in chat per scrivere, correggere e comprendere codice;
- supporto a più provider LLM (OpenAI, Codex CLI, Claude Code CLI);
- integrazione MCP (Model Context Protocol) e cronologia conversazioni persistente.

L'obiettivo principale dell'app è offrire un'esperienza "Cursor-like" su macOS, con un assistente AI direttamente dentro l'IDE per velocizzare il flusso di sviluppo.
